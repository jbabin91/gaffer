# Research

Prior art, community findings, and UX research.

Research docs capture what we learned from external sources so the same ground isn't covered twice.

## Conventions

- File naming: `NNNN-short-title.md`
- Keep findings concise: bullet points over prose.
- Cite sources where possible.
- Link to the idea or spec that prompted the research.

## What belongs here

- How other career-mode trackers and squad planners solve a problem
- Library behavior discoveries (PGlite, Drizzle, React Aria quirks)
- UX patterns worth borrowing

## What does NOT belong

- Decisions (those belong in `docs/decisions/`)
- Feature designs (those belong in `docs/specs/`)
- Game mechanics reference (that belongs in `docs/game/`)

## Template

Use `docs/research/0000-template.md`.
