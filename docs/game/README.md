# Game reference

How EA Sports FC 26 manager career mode works, in our own words — the reference
that shapes the data model and features.

These are working notes on game mechanics, not EA data. They exist so the schema
and features reflect how the game actually behaves. Verify specifics against the
live game; mechanics shift between editions.

## What belongs here

- Career-mode systems: seasons, transfer windows, objectives, budgets
- Player systems: ratings, growth, form, contracts, positions
- Anything about how the game works that justifies a field or feature

## What does NOT belong

- Our app's design choices (those are `docs/decisions/`)
- Feature designs (those are `docs/specs/`)
- EA branding, crests, photos, or licensed data (see
  `docs/development/data-compliance.md`)

## Contents

- `career-mode.md` — seasons, transfer windows, objectives, board expectations
- `player-development.md` — overall, potential, growth, form, age
- `youth-academy.md` — youth scouting, potential margins by age, reveal method
- `transfers-and-finances.md` — transfer and wage budgets, windows, deals
- `positions-and-roles.md` — position codes and secondary positions
